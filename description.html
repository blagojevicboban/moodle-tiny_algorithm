Tiny Algorithm: Flowchart Editor

Draw algorithms as flowcharts right in the Moodle text editor, run them step by step and turn them into code.

Features

  • Visual editor: Declare, Assign, Input, Output, If, For, While, Do...While, Call, Return, Comment; several functions, undo / redo.
  • Interpreter: Run / Step / Stop, console with input, variable watch, infinite-loop guard and clear error messages.
  • Flowgorithm files: import and export real .fprg files.
  • Code generation: Python, C, Java and C#.
  • Editable images: the diagram is an SVG image that keeps its model; double-click to edit again. Zoom and per-diagram options included.

What's new in 0.4.0

  • Supports Moodle 4.5 LTS and 5.0 - 5.3 (tested on all of them).
  • Serbian Cyrillic language files; the editor picks Latin or Cyrillic from the Moodle language.
  • Moodle coding standard (phpcs, ESLint, stylelint) and GitHub Actions with moodle-plugin-ci.

Requirements

  • Moodle 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • Companion plugins (optional): filter_algorithm (Run / Step for readers) and qtype_algorithm (quiz question type).

Privacy

The editor and interpreter run in the browser; nothing is sent to external services. The diagram is stored in the text you save. The plugin keeps two display preferences (code and variable panels) in the browser's local storage and implements the Moodle Privacy API (no personal data stored).
