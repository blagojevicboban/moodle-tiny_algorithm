Tiny Algorithm: Flowchart Editor

Draw algorithms as flowcharts right in the Moodle text editor, run them step by step and turn them into code.

Features

  • Visual editor: Declare, Assign, Input, Output, If, For, While, Do...While, Call, Return, Comment; several functions, undo / redo.
  • Interpreter: Run / Step / Stop, console with input, variable watch, infinite-loop guard and clear error messages.
  • Flowgorithm files: import and export real .fprg files.
  • Code generation: Python, C, C++, Java, C#, JavaScript and Pascal.
  • Editable images: the diagram is an SVG image that keeps its model; double-click to edit again. Zoom and per-diagram options included.
  • Students edit and test: with filter_algorithm, students can change their own copy of a diagram in any content and run the teacher's tests.
  • Tests from the solution: the teacher enters only the inputs; the expected outputs are computed from the teacher's solution.

What's new in 1.0.0

  • Stable release.
  • Three more languages: the generated code is now also available in C++, JavaScript (Node.js) and Pascal (Free Pascal), next to Python, C, Java and C#.
  • Generated code keeps the parentheses of the expression, so (a + b) * 2 and not (a or b) compute what the diagram computes.
  • All texts of the editor come from the Moodle language files and can be translated in AMOS.
  • Since 0.5: students can edit and test a diagram in any content when the teacher allows it, tests computed from the teacher's solution, a starting template.

Requirements

  • Moodle 4.5 LTS to 5.3 (PHP as required by your Moodle version).
  • Companion plugins (optional): filter_algorithm 1.0.0 (Run / Step and the student features for readers) and qtype_algorithm 1.0.0 (quiz question type with automatic grading).

Privacy

The editor and interpreter run in the browser; nothing is sent to external services. The diagram is stored in the text you save. The plugin keeps two display preferences (code and variable panels) and the student's own copy of an editable diagram in the browser's local storage and implements the Moodle Privacy API (no personal data stored).
